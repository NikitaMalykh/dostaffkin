# Dostaffkin

Веб-приложение для оформления и отслеживания доставки посылок. Пользователь может выбрать маршрут, рассчитать стоимость, оформить заявку и получить информацию о статусе отправления.

## Основной функционал

- Главная страница с навигацией по сервису
- Оформление доставки:
  - указание пункта отправления и назначения
  - выбор размера посылки
  - выбор скорости доставки
  - построение маршрута на карте
  - расчёт стоимости и длительности доставки
  - отправка заявки на сервер
- Отслеживание посылки по номеру
- Уведомления об ошибках и успешных действиях

## Интеграции

Приложение использует внешний сервис доставки для:

- создания заявок
- получения информации о статусе отправления

## Технологический стек

- Angular 21
- TypeScript
- RxJS
- Angular Forms / Router
- ngx-toastr
- Yandex Maps API
- npm / Angular CLI

## Установка и запуск

```bash
npm install
npm start
```

Откройте приложение в браузере по адресу http://localhost:4200.

## Сборка

```bash
npm run build
```
